# arr-mcps

Model Context Protocol (MCP) servers for the self-hosted **arr** stack and
adjacent media and utility services. Built with
[FastMCP](https://gofastmcp.com).

Each MCP is an independent project with its own repository, versioning, and
releases — browse them all below.

## Index

The canonical index and working tree lives in
[**arr-mcps/arr-mcps**](https://github.com/arr-mcps/arr-mcps): tool docs,
installation instructions, release notes, and the `new-mcp` wizard that
scaffolds new servers.
